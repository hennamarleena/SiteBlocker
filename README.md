# SiteBlocker

## About the project
- Chrome extension to block websites chosen by the user

## Properties (coming up):
- Adding blocked sites: input the URL of the website and add it to the list
- Chosen sites are blocked by using chrome.declarativeNetRequest API
- Deleting blocked sites from the list
- Blocking currently open tab by clicking "block current tab"
- Storage in chrome.storage.local

**Right now working:**
- Adding a website to the list by input ✔️
- Adding currently open tab to the list ✔️
- Deleting website from the list and chrome.storage.local ✔️
- Doesn't block anything yet ❌

## Installation:
- Download the zip file
- Open Chrome -> extensions -> developer mode on -> load unpacked
